# ActionLens Design System

Embodying the **29 Master Design Patterns**:
- **Bento Grid (#12)**: Asymmetric layout organizing pipeline execution metrics, critical paths, and security findings.
- **Dark Mode UI (#20)**: Deep carbon canvas `#070a12` with neon cyan and amber status highlights.
- **Cybercore (#24)**: High-density CI/CD job topology diagrams with terminal monospace styling.
